# Inventory Management System

## Overview

A console-based Inventory Management System developed in Python to manage product stock, update inventory quantities, generate invoices, and apply promotional discounts.

## Features

* Display inventory
* Increase product quantity
* Decrease product quantity
* Generate purchase invoices
* Buy Three Get One Free promotion
* File-based data storage
* Error handling and input validation

## Technologies Used

*  Python
* File Handling
* Modular Programming
* Exception Handling
